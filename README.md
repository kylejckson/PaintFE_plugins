# PaintFE community plugins

Portable script effects for PaintFE, with native dialogs and local image processing.

**Requires a PaintFE build with Script Plugin API 1. The Plugin Browser is currently under development and may not be present in the latest stable PaintFE release.**

In a compatible build, open **Filter > Browse plugins**, choose **Fetch catalogue**, then install a pack. Fetching listings and downloading packs connects to GitHub. Installed effects run offline. You can also import a `.pfeplugin` file without connecting.

## Available packs

- **Colour Workshop:** Duotone and Channel Shift.
- **Glitch Workshop:** Scanlines and Row Offset.

These are original MIT-licensed examples. Other contributors retain their chosen licences.
