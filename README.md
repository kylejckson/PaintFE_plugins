# PaintFE community add-ons

Community effects, themes and icon packs for PaintFE. Script effects use native dialogs and process images locally.

**Requires PaintFE 1.5.0 or newer, with Community add-ons and API 1.**

In a compatible build, open **View > Community add-ons**, choose **Fetch add-ons**, then install a pack. Fetching listings and downloading packs connects to GitHub. Installed effects run offline. You can also import a `.pfeplugin` file without connecting.

## Available packs

- **Two Tone:** two-colour treatments for prints and posters.
- **Paper Grain:** a little texture with adjustable grain size.
- **Colour Offset:** channel fringes and misprint effects.
- **Soft Vignette:** soft edge darkening with an adjustable centre.
- **Glass Dark and Glass Light:** charcoal and pearl-white themes with blue accents, translucent surfaces and optional native desktop blur.

These are original MIT-licensed examples. Other contributors retain their chosen licences.

No account is needed to download public packs. Comments, submissions and reports use GitHub. The repository does not collect app telemetry or user documents.

Earlier Workshop packs are retained under `examples/legacy` for authors. Effects, themes and icon packs are supported in PaintFE 1.5.0. Installation never applies a theme automatically.

Luminous is already the default icon family in PaintFE; Classic remains available in Preferences. The icon-pack format example is kept under examples/legacy, outside the downloadable catalogue.

## Theme collection

Ten themes and the separate Retro 98 Icons pack, all authored by kylejckson,
are available through View > Community add-ons. The collection includes
Charcoal Frosted Aero, Charcoal Sharp Glass, Retro 98, Retro XP, Paper Studio,
Graphite Studio, Northern Mist, Moss Terminal, Amber Console and Pearl Aero.

PaintFE 1.5.0 supports the colours and layouts. Grain, raised retro control
edges and solid accent headers need a newer client containing those finishes.
The current release safely ignores those extra appearance options. Native
blur also depends on platform support. See [the collection guide](docs/theme-collection.md).
